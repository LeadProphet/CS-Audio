# Audio

## Music
Progress: 🟩🟩🟩🟩🟩⬜⬜⬜⬜⬜ 50%

Loose `.ogg` files can be found in the install directory. Cyberstorm allowed players to 'stream' the [Red Book](https://en.wikipedia.org/wiki/Compact_Disc_Digital_Audio) music from the game CD to avoid useing hard drive space (1996 woes). The `.ogg` files should be the same songs as the Red Book audio however the Red Book audio should be higher quality as the provided `.ogg` may have been quality reduced for 1996 resource constraints.

Next step: Extract the Red Book audio direct from disk (Cannot be done from GOG version).
